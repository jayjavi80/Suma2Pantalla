# Reglas del proyecto

## Tecnología

- HTML5
- CSS3
- JavaScript
- Phaser cuando sea necesario

## Diseño

- Los juegos deben adaptarse a diferentes resoluciones.
- Deben funcionar en pantallas táctiles.
- No utilizar dimensiones fijas que provoquen desbordamientos.
- Mantener una resolución lógica de 1920x1080 cuando sea apropiado.

## Compatibilidad

- Windows
- Chrome
- Edge
- Android WebView

## Código

- No eliminar funcionalidades existentes sin autorización.
- No modificar archivos que no sean necesarios.
- Mantener el código organizado.
- Evitar dependencias innecesarias.

## Antes de terminar

- Revisar errores JavaScript.
- Revisar consola.
- Comprobar adaptación a diferentes resoluciones.
- Comprobar funcionamiento táctil.
- Revisar que los recursos utilizados existan.
